## System Flow

User → Blade UI → Route → Controller → Model → SQLite Database

The user interacts with the Blade pages. The routes send the request to the Task Controller. The controller uses the Task Model to save, update, retrieve, or delete data from the SQLite database. The result is then displayed back on the Blade pages.
